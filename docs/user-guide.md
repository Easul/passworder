# 用户指南

## 首次使用

1. 运行 `./dist/passworder` 启动服务
2. 浏览器访问 `http://localhost:18080`
3. 设置主密码（至少 8 位）
4. 开始使用

## 账号管理

### 添加账号
- 点击右上角「➕ 添加」
- 填写标题、用户名、密码等信息
- 选择分类（网站/工作/社交/金融/游戏/其他）
- 可选：设置登录提醒日期和提醒邮箱
- 可选：设置账号状态（有效/无效）和注册信息

### 密码生成
- 在账号表单中点击「生成密码」
- 可配置长度、大小写、数字、符号
- 一键填入表单

### 搜索与筛选
- 顶部搜索框支持按标题、用户名、网站、备注搜索
- 分类下拉框可按分类筛选
- 收藏账号显示在最前面
- 无效账号不参与邮件提醒

### 导入导出
- 进入「设置」-「导入导出」
- 支持 JSON、CSV 格式
- ZIP 格式备份包含账号、分类、笔记及附件

## 笔记管理

### 创建笔记
- 切换到「笔记」页面
- 点击「➕ 新建」
- 选择格式：纯文本 或 Markdown
- Markdown 模式使用 Vditor 编辑器，支持实时渲染

### 浏览笔记
- 笔记条目右上角点击「浏览」按钮
- 在弹窗中查看 Markdown 渲染或纯文本内容
- 支持预览笔记中的附件

### 添加附件
- 在笔记编辑窗口中选择文件
- 支持同时选择多个文件
- 已选文件会显示在列表中，可移除
- 保存后自动上传

### 预览附件
- 图片：直接弹窗预览
- 压缩包（zip）：显示内部文件列表
- 文档（docx/xlsx/txt/csv）：在线预览内容
- PDF：全屏预览

### 回收站
- 删除的笔记进入回收站
- 可从回收站恢复笔记
- 清空回收站将永久删除笔记和附件

## 邮件提醒

### 设置发信邮箱
1. 点击「设置」
2. 填写 SMTP 信息：
   - SMTP 服务器地址和端口
   - SMTP 用户名和密码
   - 发信邮箱和名称
3. 点击「保存邮件设置」
4. 在「提醒邮箱列表」中可添加多个提醒邮箱

### 设置账号提醒
1. 编辑账号
2. 在「登录提醒」中选择提醒日期时间
3. 从下拉框选择「提醒邮箱」
4. 保存

### 发送提醒
- 手动：在设置中点击「发送到期提醒」
- 系统会自动汇总当天到期的所有账号
- 按收件人分组，发送一封汇总邮件

## 数据备份

### 导出
- 进入「设置」
- 点击「导出数据」
- 下载 JSON、CSV 格式的备份文件
- 或下载 ZIP 格式完整备份（包含附件）

### 导入
- 进入「设置」
- 点击「导入数据」
- 选择之前导出的 JSON、CSV 或 ZIP 文件
- 确认导入

## 快捷键

- `Escape`：关闭弹窗
- `Ctrl+Enter`（在笔记编辑器内）：保存并关闭
- Markdown 编辑器内支持常用快捷键（Ctrl+B 粗体、Ctrl+I 斜体等）

## 常见问题

### 如何更改端口？
```bash
./dist/passworder --port 9000
```

### 如何在公网访问？
```bash
./dist/passworder --host 0.0.0.0 --port 18080
```
**注意**：公网访问时建议配置防火墙和 HTTPS。

### 数据存储在哪里？
- 数据库：默认保存在程序所在目录的 `password.db`（可通过 `--db` 指定其他路径）
- 文件存储：默认保存在程序所在目录的 `storage/` 目录（可通过 `--storage` 指定其他路径）
- 重要：无论从哪个目录运行程序，数据总是存储在程序所在目录，而不是运行目录

### 忘记主密码怎么办？
由于使用强加密，忘记主密码无法恢复数据。建议定期备份。
